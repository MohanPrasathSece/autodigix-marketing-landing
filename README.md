# Digital Launchpad

Create a premium, modern, high-converting single-page landing website for AUTODIGIX — AI Automation & Digital Marketing.

Use the provided reference image as the visual direction, but DO NOT copy the layout exactly. Create an original, more polished, cinematic and professional design.

CORE DESIGN DIRECTION

Theme:

Premium blue + white

Clean, futuristic, technology-driven

Modern SaaS / AI startup aesthetic

Minimal but visually impressive

Strong typography

Large whitespace

Smooth rounded containers

Subtle depth and soft shadows

Cinematic visuals

Professional, trustworthy and conversion-focused

Primary colors:

White: #FFFFFF

Deep navy: #071A35

Primary blue: #1769FF

Bright blue: #3B82F6

Very light blue: #F2F7FF

Soft sky blue: #EAF3FF

Text gray: #64748B

Avoid:

Dark full-page backgrounds

Excessive gradients

Excessive glassmorphism

Neon cyberpunk styling

Too many cards

Too many decorative elements

Excessive animations

Generic template appearance

Emoji icons

Cartoon graphics

Overcrowded sections

Use professional UI symbols, thin line icons and subtle graphical elements instead of emojis.

TYPOGRAPHY

Use a premium modern sans-serif font such as:

Inter

Geist

Manrope

Plus Jakarta Sans

Headings should be bold, large and highly readable.

Hero headline should feel cinematic and editorial rather than like a generic marketing template.

Use strong hierarchy:

Huge hero headline

Medium section headings

Small uppercase labels

Comfortable body text

Generous line-height

GLOBAL UI STYLE

Every major content container should use:

20px–32px border radius

Very subtle borders

Soft shadows

Large internal padding

Consistent spacing

Buttons should have:

12px–16px radius

Strong blue background

White text

Subtle hover animation

Arrow or professional directional icon

No emoji

Use thin blue borders and subtle blue glow only where appropriate.

The website must feel expensive, refined and professionally designed.

VISUAL SYSTEM

Use consistent 24px–32px rounded corners.

Use large 1200–1400px maximum content width.

Use generous vertical spacing between sections.

Hero should have approximately 80–100vh visual impact.

Use smooth scroll animations:

Fade-up

Slight scale

Parallax

Soft floating motion

Animations must be subtle and premium.

Do NOT use excessive bouncing, spinning or flashy effects.

Use blue gradients only as atmospheric accents.

Use realistic 3D/futuristic visual elements sparingly.

The shuttle should be a recurring visual motif representing launch, progress and digital transformation.
